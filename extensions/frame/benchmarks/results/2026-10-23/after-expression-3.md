Expression benchmark: RuntimeGraph source -> fused filter(source, col("score") + 1 > threshold) -> count sink. Each source seeds 100,000 keyed rows and removes 10,000 IDs, leaving 90,000 rows. Clustered layout removes the final 10,000 IDs; scattered layout removes every tenth ID. Initial scores are 100 for IDs where id % 100 < 50 and 0 otherwise, with threshold 50, so both layouts select 45,000 rows. The cycle clock is separately scheduled; source and threshold consume its tick, and the sink consumes both the filtered TSF and the tick. Threshold nodes publish only when the threshold changes. Graph wiring and compilation are excluded. Runtime allocation, start plus seed, first evaluation, steady cycles, stop, and destruction are timed separately. The first evaluation and two warmup cycles are excluded from steady timings; eleven cycles are measured. Lifecycle timings are single samples. Steady cycle timings are median [min, max] in milliseconds. Counts and filtered row totals are validated outside each timed evaluation.
