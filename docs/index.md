# BG documentation

BG connects calculations whose inputs change over time. Describe how outputs
depend on inputs, then let BG evaluate the calculations as updates arrive.

The user guide introduces graphs through complete Python and C++ examples.
Choose a language tab; the site remembers your choice across examples and
pages. You need basic knowledge of functions and types in your chosen language.
Graph programming is introduced from the beginning.

Start with [Introduction to BG](guide/index.md), or
[install BG](guide/installation.md) and run [Your first graph](guide/getting-started.md).
